One sentence pitching the worst, most useless app imaginable — an entry for the
[make.fun bounty](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

> ScreamTune turns your 3 a.m. screams into custom ringtones, auto-shares them with your contacts, and charges $0.99 per scream — your most-played ringtone is already your boss's voicemail.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` (one line,
187 UTF-8 characters, inside the 1–200 gate).
